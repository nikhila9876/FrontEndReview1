# 7. OTP API

Create an endpoint similar to:

```text
POST /api/auth/verify-otp
```

Request:

```json
{
  "email": "user@example.com",
  "otp": "123456"
}
```

The backend must verify:

1. User exists.
2. OTP exists.
3. OTP has not expired.
4. OTP matches.
5. User is not already verified.

If successful:

```text
isEmailVerified = true
```

Then invalidate/delete the OTP.

Return a clean success response.
